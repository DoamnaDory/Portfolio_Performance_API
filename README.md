# 💼 Portfolio Performance API

Микросервис для управления инвестиционными портфелями и расчёта их доходности.

## 🔎 Возможности

- Создание портфелей
- Добавление транзакций покупки/продажи
- Расчёт текущей стоимости портфеля и ROI
- Интерактивная документация Swagger
- Полная контейнеризация Docker

## 📦 Стек технологий
- Python 
- FastAPI - фреймворк
- PostgreSQL + asyncpg - асинхронная работа с БД
- SQLAlchemy - ORM
- Alembic - миграции
- Pydantic - валидация и настройки
- Docker + docker-compose - контейнеризация

## 📁 Назначение ключевых директорий
- app/api - Содержит FastAPI-роуты. Преобразует HTTP-запросы в вызовы сервисов и формирует ответы.
- app/domain - Бизнес-логика: расчёт доходности, управление портфелями и транзакциями. Здесь же находятся Pydantic-модели (DTO), которые определяют контракты API.
- app/infrastructure - Работа с внешними ресурсами: PostgreSQL (репозитории, ORM-модели), файловая система (загрузка цен и маппинга тикеров).
- app/core - Конфигурация приложения, загрузка переменных окружения, общие утилиты.
- alembic - Миграции схемы базы данных.
- data - Статические файлы: csv с ценами акций, json с соответствием тикеров и названий компаний.
